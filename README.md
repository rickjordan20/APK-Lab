# APK LAB — Do código ao Android

Site educacional interativo e responsivo para estudantes do curso Técnico em Desenvolvimento de Sistemas aprenderem a gerar APK Android usando React Native, Expo e EAS Build.

## Tecnologias

HTML5, CSS3 e JavaScript puro. Sem build step, backend ou dependências obrigatórias.

## Recursos

- 23 etapas organizadas em seis módulos;
- Explicações didáticas e exemplos de comandos;
- Simulador educativo de terminal (não executa comandos reais);
- Botões para copiar comandos;
- Quizzes com feedback e checklists;
- Progresso salvo no navegador (localStorage);
- Pesquisa, glossário, tema claro/escuro e layout responsivo.

## Executar localmente

Abra `index.html` no navegador. Para testar com servidor local, use a extensão Live Server do VS Code ou `python -m http.server 8000` e acesse `http://localhost:8000`.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub, por exemplo `apk-lab-manual`.
2. Envie `index.html`, `styles.css`, `script.js` e `README.md` para a raiz da branch `main`.
3. No repositório, acesse **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, `main` e `/ (root)`; salve.
5. Aguarde a publicação e abra `https://SEU-USUARIO.github.io/apk-lab-manual/`.

## Observações

O simulador é ilustrativo. Nenhum comando é executado de verdade. O resultado de Expo Doctor 21/21 representa um caso de estudo, não um resultado universal. Verifique versões e procedimentos na [documentação Expo](https://docs.expo.dev/).
